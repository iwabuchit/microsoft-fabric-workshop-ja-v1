モジュール5. Power BIレポートの作成

📢 導入

このモジュールでは、Synapse Data Warehouse に格納された NYC Taxi Dataset をもとに、セマンティックモデルの構築から Power BI によるレポート作成までを行います。Copilot を活用することで、視覚的な分析やエグゼクティブサマリーの生成を効率的に進めることができ、データに基づいた意思決定を支援するレポート作成スキルを習得します。

🎯 ゴール

  • セマンティックモデルの構築とリレーションの設定
  • Power BI によるレポートの自動生成と編集
  • Copilot を活用したレポートの強化と要約の作成
  • レポートの保存とワークスペースへの反映

セマンティック モデルの作成

  1. タスクフローの処理されたデータをクリックしアイテムをフィルタしてウェアハウスを選択します。

  2. モデルレイアウトをクリックしfact_greentrip[_copilot]をディメンジョン表の下に移動します。

    Info

    画面が見にくい場合は、右下でズームを変えてください。
    画面右側のプロパティを折りたたむこともできます。

  3. fact_greentrip[_copilot]のpayment_type列をdimension_PaymentTypeのpayment_type列にドラッグ＆ドロップします。

  4. 多対一のリレーションシップになっていることを確認して保存します。

  5. 同じ要領で次の列のリレーションシップを作成します。

    • RatecodeID(fact_greentrip) → RatecodeID(dimension_RatecodeID)
    • PUlocationID (fact_greentrip) → LocationID(dimension_taxiZoneLookup)
    • trip_type(fact_greentrip) → Trip_type(dimension_TripType)
    • VenderID(fact_greentrip) → VenderID(dimension_VenderID)

  6. 報告タブからセマンティックモデルオブジェクトを自動的に更新するを選択します。

  7. モデル更新が完了すると、スタースキーマ型にモデルレイアウトが更新されます。

Power BIレポートの作成

  1. 自身のワークスペースのタスクフローの処理されたデータをクリックしアイテムをフィルタしてセマンティックモデルを選択します。

  2. このデータを探索する＞レポートの自動作成を選択します。

  3. レポートが自動作成されるので編集をクリックします。

    この時点ではまだCopilot機能は使用されていません。

  4. Copilotをクリックします。

  5. チャットに次の文章を入力し送信します。

    テキスト

    FactTrips を使って 概要ページを1枚作成。カードで 合計乗車回数、合計売上(Total_amount)、
平均距離(Trip_distance) を表示し、日別折れ線 と 支払い方法別の棒グラフ(Payment_type) を追加。

  6. Copilotによってレポートが作成されます。

    Info

    必ずしも上記と同じレポートが作成されるとは限りません。
    以降の手順はご自身のレポートに置き換えて操作してください。

  7. いくつかのビジュアルをクリックし縮めたり移動してスペースを確保します。

  8. 確保したスペースをクリックし視覚化から説明のアイコンを選択しCopilotをクリックします。

  9. エグゼクティブ サマリーを提供するをクリックし更新します。

  10. 表示が更新されない場合は更新をクリックしてください。

  11. エグゼクティブ サマリーが作成されたら任意の場所の番号をクリックします。

  12. 該当箇所にフォーカスが当たることを確認します。

  13. チャットに自由にメッセージを入れてCopilotの応答を確認してください。

    入力例

    このレポートを使って上司に説明をします。重要なポイントを日本語で3つ教えてください。

    入力例

    上司に説明をした際に想定される質問3つとその答えを教えてください。

  14. ファイルから名前を付けて保存を選択します。

  15. 次の情報を入力して保存します。

    レポートの名前

    [イニシャル][2桁の数字]_17_report_warehouse_quick_summary_and_copilot

    タスク

    視覚化

  16. ワークスペースに戻るので右上にあるデータ系列ビューアイコンをクリックします。

  17. 今回作成したアイテムの関連が表示されます。
