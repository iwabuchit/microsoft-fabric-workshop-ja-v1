モジュール3. データ取り込みと準備

📢 導入

このモジュールでは、ハンズオン ワークショップで利用するワークスペースを作成します。既に作成済みの環境を利用する際はスキップしてください。

🎯 ゴール

  • ワークスペースの作成

ショートカットの作成

  1. エクスプローラーのFilesを右クリックし新しいショートカットを選択します。

  2. Azure Data Lake Storage Gen2を選択します。

  3. 新しい接続を選択し接続情報を入力します。

    URL

    https://wwilab001adls001.dfs.core.windows.net/

    接続名

    [イニシャル][2桁の数字]_06_datasource_adls

    認証の種類

    組織アカウント

  4. datasourceをチェック✅し次へをクリックします。

  5. 変換はスキップします。

  6. アクションのペンマークをクリックしショートカット名を入力しチェック✅後に作成をクリックします。

    ショートカット名

    [イニシャル][2桁の数字]_07_shortcut_adls

ショートカットからのテーブル作成

  1. 作成したショートカットからファイルを右クリックし、テーブルに読み込む＞新しいテーブルを選択します。

  2. テーブル名がtaxi_zone_lookupとなっていることを確認して読み込みます。

  3. 作成されたテーブルをクリックして中身を確認します。

Sparkを使ったデータ加工

  1. 自身のワークスペースをクリックし、データの処理の新しい項目をクリックします。

  2. ノートブックを選択します。

  3. 左上のNotebook 1をクリックし名前を変更します。

    名前

    [イニシャル][2桁の数字]_10_notebook_create_delta_table

  4. データ項目の追加から既存のデータ ソースを選択します。

  5. 自身のデータレイクを選択し接続します。

  6. フォルダをクリックし、表示されたファイルをノートブックにドラッグ＆ドロップします。

  7. セルの左側の▶をクリックすると、処理が実行されデータが下に表示されます。

  8. 新しいグラフをクリックするとグラフに表示が切り替わります。
    編集を開始するをクリックするとさまざまなグラフに変更できます。

  9. グラフの種類や軸のデータを変更し、グラフが変化することを確認してください。
    例えば、グラフの種類を散布図に変更してX軸をtrip_distance、Y軸をtotal_amountにすると次のように表示されます。

  10. グラフの左下にマウスをホバーさせて＋コードをクリックしセルを追加します。

  11. 追加されたセルに次のコードを入力します。

    #1
df_clean = df.drop('ehail_fee')
display(df_clean)

  12. 同じ要領でセルを追加して次のコードを入力します。

    #2
display(df_clean.groupBy('passenger_count').count())

    #3
from pyspark.sql.functions import col
df_clean = df_clean.filter(col('passenger_count') > 0)

    #4
display(df_clean.groupBy('passenger_count').count())

    #5
table_name = 'curated_green_tripdata_2022_12'
df_clean.write.mode("overwrite").format("delta").save("Tables/" + table_name)

  13. 5つのセルの入力が完了したらすべて実行をクリックします。
    すべてのセルでエラーが発生していないことを確認します。

  14. エクスプローラーのTablesを右クリックし、最新の情報に更新します。

  15. ノートブックで作成されたテーブルcurated_green_tripdata_2022_12が作成されていることを確認します。
