モジュール6. Data Agent の作成

📢 導入

このモジュールでは、Microsoft Fabric の Data Agent 機能を活用して、自然言語でデータに対する質問を投げかけ、インサイトを得ることができる AI エージェントを構築します。Data Agent は、構築したデータウェアハウスやセマンティックモデルに対して、技術的な知識がなくても誰でも簡単にデータ分析を行えるようにする強力なツールです。

🎯 ゴール

  • Data Agent の作成と基本設定の理解
  • セマンティックモデルとの接続設定
  • 自然言語クエリによるデータ探索
  • エージェントの動作確認とテスト

タスクの追加

  1. 自身のワークスペースからタスクの追加からデータの分析とトレーニングをクリックします。

  2. 分析とトレーニングを可視化の下に移動し、処理されたデータの右端をドラッグして分析とトレーニングの左端に矢印を伸ばします。

  3. 以下のようになります。

Data Agent の作成

  1. ワークスペースをクリックしタスクフローの分析とトレーニングから新しい項目を選択します。

  2. データ エージェントを選択します。

  3. 名前を入力して作成します。

    名前

    [イニシャル][2桁の数字]_18_data_agent_taxi

データソースの接続

  1. Data Agent の作成画面が表示されたらデータの追加＞データ ソースをクリックします。

  2. セマンティックモデル（[イニシャル][2桁の数字]_16_semantic_model_taxi）を選択します。

  3. すべてのテーブルをチェックします。

エージェントの設定

  1. 説明アイコンをクリックしエージェントの説明を入力します。

    説明

    このエージェントは、NYC タクシーデータセットに関する質問に回答します。
トリップ情報、支払いタイプ、場所、ベンダー情報などのデータを分析できます。

  2. 指示タブに移動し、エージェントの動作に関する指示を入力します。

    エージェントの指示

    以下の指示に従ってください：
- ユーザーの質問を丁寧に理解し、適切なテーブルとカラムを使用してください
- 数値は適切にフォーマットして表示してください（例：金額は小数点2桁まで）
- 日付や時間に関する質問には、適切な集計レベルで回答してください
- わからない場合は、利用可能なデータの範囲を説明してください
- 回答は日本語で提供してください

エージェントのテスト

  1. 次の質問を入力してエージェントをテストします。

    最も多く利用されている支払いタイプは何ですか？

    クレジットカードによる支払いが最も多いと返ります。

  2. より複雑な分析を依頼してみます。

    支払い種別毎に、平均料金、平均チップ、平均距離を表にまとめてください

  3. 手順が完了しましたを展開し、右端の∨を展開します。

  4. エージェントが実行した DAX クエリとその結果を確認します。

    Info

    このクエリ履歴は、エージェントがどのようにユーザーの質問を解釈し、データクエリに変換しているかを理解するのに役立ちます。

Data Agent を活用することで、技術的な知識がないユーザーでも、自然言語でデータに対する質問を投げかけ、即座にインサイトを得ることができます。これにより、組織全体でのデータ活用が促進され、データドリブンな意思決定を加速できます。
