モジュール4. ウェアハウスの構築

📢 導入

このモジュールは、Synapse Data Warehouseを使用してNYC Taxi Datasetの追加のテーブル(ディメンションとファクト)を取り込みます。データの取り込みに関してはT-SQLやCOPY、Dataflowを使用します。また取り込んだデータを使用してモデルを作成しレポートを作成します。

🎯 ゴール

  • ワークスペースの作成

ウェアハウスの作成

  1. ワークスペースをクリックしタスクフローの処理されたデータから新しい項目を選択します。

  2. ウェアハウスを選択します。

  3. 名前を入力して作成します。

    名前

    [イニシャル][2桁の数字]_12_warehouse_taxi

ディメンジョン テーブルの作成

  1. 次のような画面が表示されるので新規SQL クエリを選択します。

  2. 作成されたSQL query 1を右クリックしRenameを選択します。

  3. 名前を入力して変更します。

    名前

    [イニシャル][2桁の数字]_13_sqlquery_create_demension_table

  4. 次のクエリをコピー＆ペーストし実行します。

    --Create dimension_VendorID table
DROP TABLE IF EXISTS [dbo].[dimension_VendorID];
CREATE TABLE [dbo].[dimension_VendorID]
(
    VendorID  [int] NULL,
    Description [VARCHAR] (100) NULL,
);

--Insert Payment_VendorID data
INSERT INTO dimension_VendorID (VendorID, Description) VALUES
    (1, 'Creative Mobile Technologies, LLC'),
    (2, 'VeriFone Inc.');

--Create dimension_TripType table
DROP TABLE IF EXISTS [dbo].[dimension_TripType];
CREATE TABLE [dbo].[dimension_TripType]
(
    Trip_type  [int] NULL,
    Description [VARCHAR] (100) NULL,
);

--Insert Payment_type data
INSERT INTO dimension_TripType (Trip_type, Description) VALUES
    (1, 'Street-hail'),
    (2, 'Dispatch');

--Create dimension_RatecodeID table
DROP TABLE IF EXISTS [dbo].[dimension_RatecodeID];
CREATE TABLE [dbo].[dimension_RatecodeID]
(
    RatecodeID [int] NULL,
    Description [VARCHAR] (100) NULL,
);

--Insert RatecodeID data
INSERT INTO dimension_RatecodeID (RatecodeID, Description) VALUES
    (1, 'Standard rate'),
    (2, 'JFK'),
    (3, 'Newark'),
    (4, 'Nassau or Westchester'),
    (5, 'Negotiated fare'),
    (6, 'Group ride');

--Create dimension_PaymentType table
DROP TABLE IF EXISTS [dbo].[dimension_PaymentType];
CREATE TABLE [dbo].[dimension_PaymentType]
(
    Payment_type  [int] NULL,
    Description [VARCHAR] (100) NULL,
);

--Insert Payment_type data
INSERT INTO dimension_PaymentType (Payment_type, Description) VALUES
    (1, 'Credit card'),
    (2, 'Cash'),
    (3, 'No charge'),
    (4, 'Dispute'),
    (5, 'Unknown'),
    (6, 'Voided trip');

--Create dimension_taxiZoneLookup table
DROP TABLE IF EXISTS [dbo].[dimension_taxiZoneLookup];
CREATE TABLE [dbo].[dimension_taxiZoneLookup]
(
    LocationID [int] NULL,
    Borough [VARCHAR] (50) NULL,
    Zone [VARCHAR] (50) NULL,
    service_zone [VARCHAR] (50) NULL,
);

-- Insert taxi_zone_lookup data from Lakehouse
INSERT INTO [dbo].[dimension_taxiZoneLookup]
SELECT *
FROM [ms01_01_lakehouse_taxi ※自身で作成されたレイクハウスに変更].[dbo].[taxi_zone_lookup];

  5. 終了すると画面下に✅成功と出力されます。

  6. Schemas＞dbo＞Tablesと展開します。5つのテーブルが作成されていることを確認します。

    • dimension_VendorID
    • dimension_TripType
    • dimension_RatecodeID
    • dimension_PaymentType
    • dimension_taxiZoneLookup

データフロー Gen2 を使用したデータ取込み

  1. 自身のワークスペースをクリックしタスクフローのデータの処理から新しい項目を選択します。

  2. データフロー Gen2を選択します。

  3. 名前を入力Git 統合・・・のチェックを外して作成します。

    名前

    [イニシャル][2桁の数字]_15_dataflow_taxi

  4. データの取得をクリックします。

  5. 自身で作成した [イニシャル][2桁の数字]_01_lakehouse_taxi を選択します。

  6. green_tripdata_2022_12 をチェックし作成をクリックします。

Info

Copilotを利用して作業する方は こちら の手順に進んでください。

  1. 列の管理から列の選をクリックします。

  2. 次の列のチェックを外します。

    • store_and_fwd_flag
    • extra
    • mta_tax
    • improvement_surcharge
    • congestion_surcharge

  3. trip_type 列を選択し変換タブをクリックします。
    値の置換をクリックし検索する値にnullを置換後の値に0を入力しに置換します。

    trip_type 列のデータが なし の割合が変化することを確認します。

  4. データの同期先の右側の＋をクリックしウェアハウスを選択します。

  5. 接続の資格情報はデフォルトのまま次へをクリックします。

  6. ウェアハウスを選択しテーブル名を入力、次へをクリックします。

    テーブル名

    fact_greentrip

  7. 更新方法が置換になっていることを確認し、次の列の型を整数にして設定を保存します。

    • VendorID
    • PULocationID
    • RatecodeID
    • payment_type
    • trip_type

  8. 画面右下の公開をクリックしデータフローを実行します。

  9. 画面が切り替わったら作成したDataflow Gen2の右にある・・・をクリックし更新履歴をクリックします。

  10. 状態が✅成功になることを確認します。

  11. タスクフローの処理されたデータをクリックしアイテムをフィルタしウェアハウスを選択します。

  12. fact_greentrip テーブルをクリックしデータが格納されていることを確認します。

データフロー Gen2 を使用したデータ取込み（Copilot利用）

  1. 画面が遷移したらCopilotをクリックします。

  2. やりたいことに次の内容を入力し送信します。

    1. 次のカラムを削除します。
store_and_fwd_flag
extra
mta_tax
improvement_surcharge
congestion_surcharge

2. trip_type の null を 0 に置き換えます。

3. 次のカラムの型を整数にします。
VendorID
PULocationID
RatecodeID
payment_type
trip_type

  3. ナビゲーション 2 以下に3つのステップが追加されることを確認します。

    各ステップの処理内容の詳細は以下から確認できます。

  4. データの同期先の右にある＋からウェアハウスを選択します。

  5. 接続の資格情報はデフォルトのまま次へをクリックします。

  6. ウェアハウスを選択しテーブル名を入力、次へをクリックします。

    テーブル名

    fact_greentrip_copilot

  7. 内容を確認して設定を保存します。

  8. 画面右下の公開をクリックしデータフローを実行します。

  9. 画面が切り替わったら作成したDataflow Gen2の右にある・・・をクリックし更新履歴をクリックします。

  10. 状態が✅成功になることを確認します。

  11. タスクフローの処理されたデータをクリックしアイテムをフィルタしウェアハウスを選択します。

  12. fact_greentrip_copilot テーブルをクリックしデータが格納されていることを確認します。
