モジュール2. レイクハウスの構築

📢 導入

このモジュールでは、NYCタクシーデータを題材に、レイクハウスの構築からデータの取り込み・加工までを一連の流れで体験します。Data Factoryのローコード機能（Data Flow Gen2）を活用し、実践的なデータ処理スキルを身につけます。

🎯 ゴール

  • レイクハウスの作成と構成理解
  • 外部データの取り込みと保存
  • データの加工とテーブルへの書き込み

レイクハウスの作成

  1. 新しい項目をクリックしレイクハウスを選択します。

  2. データレイク名を入力し作成をクリックします。 ※Lakehouseスキーマのチェックは本手順ではチェックを入れないでください
    先頭には、[イニシャル]+[2桁の数字]_を入れてください。

    データレイク名

    [イニシャル][2桁の数字]_01_lakehouse_taxi

  3. データレイクが作成されると以下のような画面に切り替わります。

  4. Filesを右クリックし、新しいサブフォルダーをクリックします。

  5. 新しいサブフォルダー名を入力し作成をクリックします。

    フォルダー名

    [イニシャル][2桁の数字]_02_data_triprecode

TLC Web サイトからのデータの取り込み

このセクションでは、Data FactoryのDataflow Gen2を使用して、TLC Web siteからLakehouseにデータを取り込みます。

  1. 以下のサイトから、2022年12月の「Green Taxi Trip Records」を利用します。

    https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

    2022年12月の「Green Taxi Trip Records」をダウンロードします。

  2. 作成したサブフォルダを右クリックしアップロード>ファイルのアップロードをクリックします。

  3. ファイルのアップロード画面のフォルダアイコンをクリックします。

    ダウンロードしたファイルを選択します。

    アップロードをクリックします。アップロードが成功✅したら画面をクローズします。

  4. アップロードしたファイルをクリックして内容を確認します。

  5. ワークスペースから事前に設計された・・・をクリックします。

  6. SQL 分析エンドポイントを使用したデータ分析をクリックし選択します。

  7. 生データストアのクリップ アイコンをクリックします。

  8. 01_lakehouse_taxiをチェックして選択します。

    タスクに生データストアが割り当てられます。

ローコードインターフェイスを使用したデータ準備

このセクションでは、Data Factory Dataflowを使用して、データを加工しTableに書き込みます。

  1. タスクフローのデータの処理から、＋新しい項目をクリックします。

  2. データフロー（Gen2）を選択します。

    Info

    データフロー（Gen2）が表示されない場合は、タスクを一度他のものに切り替えてください。

  3. 名前を入力しGit統合のチェックを外し作成をクリックします。

    名前

    [イニシャル][2桁の数字]_05_dataflow_curated

  4. メニュー右側の∨をクリックします。

  5. データを取得クリックします。

  6. 作成したデータレイクを選択します。

  7. 01_lakehouse_taxi＞ファイル＞02_data_triprecodeを展開しgreen_tripdata_2022-12.parquetをチェック✅します。
    ファイルの情報が表示されたら右下の作成をクリックします。

  8. 以下の画面が表示されます。

  9. 表示タブをクリックし、データビューの∨をクリックし列プロファイルを有効にするをチェック✅します。 その後、直下の3つをチェックすると、データの上にデータの分析情報が表示されます。

  10. 不要な列を削除します。
    ホームタブから列の管理＞列の選択をクリックします。

  11. ehail_feeのチェックを外しOKクリックします。

  12. passenger_countのなしが0%になっていることを確認します。
    上位1,000行に基づいた列のプロファイルからデータ セット全体に基づく列のプロファイルに変更します。
    passenger_countのなしの割合が変化していることを確認します。

  13. 値が入力されていないデータをきれいにします。
    passenger_count列の∨を選択し、さらに読み込むをクリックします。

    (null)のチェックを外しOKをクリックします。

  14. データをどこに保存するか選択します。
    右下のデータ同期先の右側にある＋をクリックしレイクハウスを選択します。

  15. 接続の資格情報はデフォルトのままで次へをクリックします。

  16. [ワークスペース名]＞01_lakehouse_taxiを選択、右側のテーブル名を入力し次へクリックします。

    テーブル名

    green_tripdata_2022_12

  17. あて先の設定はデフォルトのままで設定の保存をクリックします。

  18. 右下の公開をクリックします。

  19. ワークスペース画面に戻ります。処理が終わるまで2～3分ほど時間をおいてください。
    作成した05_dataflow_curatedの「・・・」から更新履歴クリックし状態を確認します。

    状態がが成功になっていれば完了です。

  20. 01_lakehouse_taxiをクリックし、エクスプローラーからテーブルが出来ていることを確認します。

    green_tripdata_2022_12をクリックすると右側にデータが表示されます。

    テーブルが正体不明（Unknown）と表示される場合は、Tablesを右クリックし最新の情報に更新してください。
